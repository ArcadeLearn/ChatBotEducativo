# ChatBotEducativo

Chatbot educativo con arquitectura híbrida: **Frontend Next.js**, **Backend NestJS**, **AI Service (LangGraph + Gemini)** y **MCP Server** con datos de campus IECA.

## Inicio rápido

Ver [COMO-INICIAR.md](./COMO-INICIAR.md) para levantar el stack local (puertos 3001, 4001, 8001, 8002).

## Estructura

| Carpeta | Descripción |
|---------|-------------|
| `frontend/` | UI del chat (Next.js) |
| `backend/` | API NestJS (auth, sesiones, proxy) |
| `ai-service/` | Agente LangGraph + tools |
| `mcp-server/` | Tools educativas (JSON) |
| `docs/` | Documentación y plan del proyecto |
